## F10.2 Drafts are not thread history
Root cause: the drafter's PREVIOUS OUTREACH block was built from every outreach_log row for the
contact, drafts included. v30 had restricted only the language resolver to sent rows; the
narrative / no-repetition path still saw Florian's two superseded drafts as "two prior messages".
v32 filters the whole thread context to Reply rows and send_status = 'Sent' before anything
reads it (language, thread text, re-engagement note). The UI sequence position is now
(sent cadence messages) + 1 via src/lib/cadence.ts, one rule everywhere. Regenerate supersedes
the prior pending draft for the touch (v29 onward) and superseded rows never feed context.

Florian's rows fixed: the 4 Sep superseded draft carries draft_language EN (it was English),
all three drafts carry created_by (Oli, Brad, Brad) and sent_by null.

Dry run after v32: thread context handed to the model = the 28 Aug connection request only;
narrative "Fresh thread opener to Florian using the specific, verified checkout gap ..." with no
mention of prior messages; touch type Initial message (position renders as message 1 of 3 in the
UI); language DE; signed Oli.

## F10.3 Draft history (Lovable cdd4a92e)
Touch popout: read-only "Draft history" under Conversation, newest first, superseded / rejected
drafts for the same contact and touch type with status chip, timestamp, requester, reason, and an
expandable body; AI-edit revisions stay in their own section. Contact popout Outreach tab: grouped
per cadence slot (First message, Chaser 1-3, Follow up), each slot reading sent row, active draft,
then earlier attempts newest first. Attribution reads "requested by <created_by>" on unsent rows
and "sent by" only on sent rows.
